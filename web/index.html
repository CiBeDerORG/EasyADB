添加设备

第一次连接？先配对无线调试

手机无线调试 → 使用配对码配对设备。这里使用配对弹窗端口；设备记录应填写无线调试主页的连接端口。

添加分组

例如组网 IP 10.10.30.206 → 内网 IP 192.168.10.206。连接地址由用户手动选择，失败不会自动回退；留空仅使用组网 IP。

首次连接 · 无线 ADB 配对

在手机上打开「开发者选项 → 无线调试 → 使用配对码配对设备」，保持配对窗口开启，再填写下面的信息。

此地址由已保存的「当前选择」决定，不能在配对弹窗中更换线路。
